# Manual QA
Привет! Меня зовут Иван. <br/>
Это портфолио создано в рамках изучения профессии QA и показывает мой подход к работе: от анализа требований до составления баг-репортов. <br/>
Здесь я собираю свои учебные и практические проекты, чтобы продемонстрировать навыки ручного тестирования. <br/>

---

## Навыки и инструменты, приобретенные в ходе обучения

| Категория | Технологии / Инструменты |
| --- | --- |
| **Тест-дизайн** | Классы эквивалентности, анализ граничных значений, таблицы решений, диаграммы состояний |
| **Документация** | [Чек-листы](https://github.com/BorhTriGalki/QA/tree/main/Test%20Artifacts), [тест-кейсы](https://github.com/BorhTriGalki/QA/tree/main/Test%20Artifacts), [баг-репорты](https://github.com/BorhTriGalki/QA/tree/main/Test%20Artifacts) |
| **Веб-тестирование** | DevTools (Elements, Console, Network), кроссбраузерное тестирование |
| **API тестирование** | Postman (коллекции, переменные, тесты), понимание REST, HTTP-методы/статусы |
| **Базы данных** | [SQL/PLpgSQL](https://github.com/BorhTriGalki/SQL) (SELECT, JOIN, WHERE, агрегатные функции) |
| **Методологии** | Agile (Scrum, Kanban), понимание жизненного цикла разработки (SDLC/STLC) |
| **Дополнительно** | Git/GitHub, командная строка |

## Структура портфолио

Этот репозиторий содержит несколько учебных проектов, каждый из которых раскрывает аспекты тестирования:
- [Чек-листы](https://github.com/BorhTriGalki/QA/tree/main/Checklists) - показывает мой подход к составлению чек-листов, на данный момент имеется разработан чек-лист проверки регистрации на сайте lamoda
- [Тест-кейсы](https://github.com/BorhTriGalki/QA/tree/main/Test-cases) - практическое умение в грамотном и понятном составлении тест-кейсов, на мой взгляд, один из основных навыков инженера по тестированию
- [Баг-репорты](https://github.com/BorhTriGalki/QA/tree/main/Bug%20report) - Как и в случае с тест-кейсом, баг-репорт крайне важно максимально понятно описать
- [Техники тест-дизайна](https://github.com/BorhTriGalki/QA/tree/main/Test%20Design%20Technics/EP%20and%20BVA) - демонстрирует умение анализировать и выбирать оптимальные тестовые сценарии
