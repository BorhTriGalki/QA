# Тест-кейсы авторизации на ya.ru

В данном проекте составил 10 тест-кейсов для проверки функциональности авторизации на сайте ya.ru. <br/>

**Объект тестирования**<br/>
Сайт: ya.ru<br/>
Раздел: Авторизация (вход в аккаунт Яндекс)<br/>
Окружение: Desktop, Windows 10 / Google Chrome<br/>

**Цель тестирования**<br/>
Проверить корректность работы механизмов авторизации:
- Вход по логину/email через пуш-уведомления
- Вход по номеру телефона
- Валидация полей
- UI/UX элементы
- Выход из аккаунта

Каждый тест-кейс содержит следующие поля:<br/>
- ID - уникальный идентификатор
- Приоритет (High/Middle/Low)
- Заголовок - краткое описание проверки
- Предусловия - что нужно сделать перед началом теста
- Шаги воспроизведения
- Ожидаемый результат<br/>
> **Также сюда можно добавить такие поля, как: <br/>- требование (ссылка на требование, для проверки которого служит кейс), <br/>- модуль (название структурной части, в которой находится предмет тестирования), <br/>- постусловия (возвращение системы в исходное состояние - удаление данных, пользователей, отключение виртуальной машины и т.д.)**

Ниже представлены сами тест-кейсы в формате markdown (ссылка на версию в [гугл-таблицах](https://docs.google.com/spreadsheets/d/172FWaRz-wamGconL6g9MxpZPWKXbVgrHqnBxTDolpFM/edit?usp=sharing))
